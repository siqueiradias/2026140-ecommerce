# CA2 – E-Commerce Web Application

Full stack e-commerce website developed for the Web Development module (CCT College Dublin).

## Planned features

- User registration and login (with password hashing)
- Product catalogue loaded from the database
- Shopping basket (add / remove items, total price)
- Simulated checkout with order confirmation

## Tech stack

- HTML, CSS, JavaScript
- Node.js + Express
- MySQL

## Status

Work in progress.
